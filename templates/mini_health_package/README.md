# riskkit

A deliberately tiny R package used in the course *Health Data Analysis with R*
(lessons 37 to 39). It converts odds ratios into absolute risks and shows the
standard package layout. **All data are simulated for teaching purposes and the
package is not intended for clinical use.**

Educational material; it does not replace a health professional.

## Layout

| Path | Purpose |
|---|---|
| `DESCRIPTION` | Name, version, authors, licence, dependencies |
| `NAMESPACE` | What the package exports; generated by roxygen2 from the tags in `R/` |
| `R/` | The functions, with roxygen2 comments |
| `man/` | Help pages; generated by `devtools::document()` (not stored in the template) |
| `tests/testthat/` | Automated tests |
| `data-raw/` | The script that builds the example data (not shipped in the built package) |

## Use it as a template

1. Copy this folder, rename it and change the `Package`, `Title`,
   `Description` and `Authors@R` fields in `DESCRIPTION`, and the holder in
   `LICENSE` and `LICENSE.md`.
2. Run `devtools::document()` to build `man/` and refresh `NAMESPACE`.
3. Run `devtools::test()` for the tests and `devtools::check()` for the full
   check.
4. Optional: run `source("data-raw/make_data.R")` to build the simulated data
   set, then follow the comments at the end of that script.

The function `or_to_absolute_risk()` is a richer sibling of the helper of the
same name in the course repository: it validates its inputs, returns an object
and has a print method.

## Example

```r
library(riskkit)
or_to_absolute_risk(c(0.5, 1, 2), baseline_risk = 0.1)
```
